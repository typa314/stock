# 📊 台股專業多維量價 + 籌碼 + 技術形態研判系統 (Taiwan Stock Quantitative & Technical Analysis)

本專案是一個專為台股（上市/上櫃）打造的專業級量價結構、技術形態、動量指標與三大法人籌碼多維研判系統。支援一鍵產出 **Plotly 互動式多層分析圖表** 與 **終端多因子專業量化研判報表**。

---

## 🌟 核心架構與功能特點

### 1. 🏛️ 上市 / 上櫃全自動支援與盤中即時行情（TWSE MIS + Yahoo 雙軌備援）
- **盤中即時行情（Live Intraday）**：在平日 09:00～13:30 交易時段內，自動串接 **TWSE MIS 官方撮合 API**（0~5 秒延遲）與 **Yahoo Finance 即時行情** 雙軌備援，自動合成當日最新盤中 K 棒（含最新現價、盤中最高、盤中最低與累積量），使 BPA 價格行為、20 EMA 與量價圖卡在盤中即時動態連動跳動。
- **上市股票（TSE）**：自動串接 TWSE 官方 API 取得完整歷史交易、盤中即時撮合與盤後三大法人數據。
- **上櫃股票（OTC）**：自動辨識並串接 yfinance（`.TWO`）歷史行情與 TWSE MIS 上櫃盤中即時撮合。
- **智慧代號解析**：輸入純數字代號（如 `3042`、`6643`）即可自動判定市場類別與官方股票簡稱。

### 2. 🧭 Stan Weinstein 四階段趨勢結構
- 不僅比對均線高低，更量化計算 **20MA（月線）與 60MA（季線）近 5 日斜率（Slope）**：
  - **第 1 階段（築底打底）**：季線下彎趨緩、月線走平糾結，進入區間打底。
  - **第 2 階段（主升推進）**：MA20 > MA60 且月線/季線雙雙向上發散，沿均線走高。
  - **第 3 階段（高檔做頭）**：股價創高後均線鈍化走平，出現高檔長上影或爆量滯漲。
  - **第 4 階段（主跌修正）**：MA20 < MA60 且月線/季線雙雙向下發散，逢反彈皆空點。

### 3. 🎯 Al Brooks 價格行為學（BPA）核心體系
- **20 EMA 動態基準線**：唯一指定核心均線，量化計算 20 EMA 近 5 日斜率與收盤乖離率。
- **Always-In 市場狀態判定**：
  - **Always In Long (AIL, 恆久做多)**：多頭強勢主控，拉回皆為買點。
  - **Always In Short (AIS, 恆久做空)**：空方強勢主導，反彈皆為空點。
  - **Trading Range (TR, 箱型區間)**：均線走平交疊，嚴守 **80% 區間突破失敗法則** 與 **BLSHS（Buy Low, Sell High, Scalp）** 原則。
- **K 線逐根識別（Bar-by-Bar Classification）**：
  - **Trend Bars（多頭 / 空頭趨勢棒）**：實體佔比 $\ge 50\%$，強勢收於極值 25% 範圍內。
  - **Reversal Signal Bars（多頭 / 空頭反轉棒）**：影線顯著拒絕（$\ge 35\%$）且收盤導向反轉方向。
  - **Inside Bar（孕線 `i`） / Double Inside（雙重孕線 `ii 突破模式`）**：動能高度壓縮之突破警訊。
  - **Outside Bar（外部棒 `o`） / Doji（十字猶豫棒）**。
- **經典高勝率交易設定（Brooks High-Probability Setups）**：
  - **High 1 / High 2 / High 3 (H1 / H2 / H3)**：多頭回檔中之二度回踩確認（H2 ABC 修正波終點，順勢最高勝率買點）。
  - **Low 1 / Low 2 / Low 3 (L1 / L2 / L3)**：空頭反彈中之二次耗竭空點（L2 經典空方高勝率放空點）。
  - **20 EMA Pullback**：強趨勢脫離後首次回測 20 EMA 動態支撐/壓力確認。
  - **20 EMA Gap Bar（乖離缺口棒）**：首次出現整根棒低於/高於 20 EMA，預警趨勢老化或終極測頂/測底。
  - **TTR（Tight Trading Range / Barbwire 鐵絲網）**：密集交疊雜訊區警訊，禁止盲目追突破。
- **台股精確 Tick 級距風控與等距測量**：
  - 自動依 TWSE 法規（0.01 / 0.05 / 0.10 / 0.50 / 1.00 / 5.00）計算 **Buy Stop / Sell Stop 掛單價** 與 **防守停損價（Protective Stop）**。
  - 自動計算 **等距測量目標（Measured Move MM +1R / +2R）**。

### 4. 🏢 三大法人籌碼圖卡與結構剖析（盤後統計）
- **三大法人專屬圖卡（Web App）**：
  - 呈現 **外資、投信、自營商** 及 **三大合計** 最新單日買賣超（台股習慣：紅買綠賣）。
  - 同步呈現 **近 5 日三大法人累計買賣超** 與公告日之 **佔量集中度**。
  - 清楚標示 **📅 公告日期**，盤中時段自動呈現前一交易日結算之法人籌碼，絕不與盤中即時量混淆。
  - 自動判斷籌碼動向態勢徽章：`🟢 土洋聯手買超`、`🔴 土洋聯手賣超`、`🔵 外資獨買`、`🟣 投信作多`、`🟡 法人偏空/動向分歧`。
  - 上櫃（OTC）股票自動優雅降級提示，不影響其他技術面與量價研判。

### 5. 📊 量價結構動能圖卡與 Wyckoff / VPA 深度評估
- **量價專屬圖卡（Web App）**：
  - 核心指標：今日成交量、20MA 均量（月基準）、量能比率（% 與倍數）、5MA 均量（週水準）。
  - 量價形態診斷徽章與操盤應對指引。
- **Wyckoff & VPA 6 大核心量價結構評估引擎**：
  - 🔥 **價量齊揚（健康放量推升）** (+2 分)
  - ▲ **帶量突破（主力放量表態）** (+2 分)
  - 🛡️ **價跌量縮（多頭良性拉回洗盤）** (+1 分 / -1 分)
  - ⚠️ **量價背離（縮量推升動能趨緩）** (0 分)
  - 💤 **窒息量打底（沉澱沉寂變盤前夕）** (0 分)
  - ⚡ **爆量滯漲（主力調節警戒）** (-1 分)
  - 🚨 **放量重挫（空方賣壓湧現）** (-2 分)
  - 正式納入 `【量價表現】` 多維量化評分體系。

### 6. 🎯 關鍵支撐壓力矩陣與具體股價操盤指引
- 自動計算多層支撐壓力位階並於終端與 Web App 輸出數值：
  - **壓力二 (R2)**：布林通道上軌 / 波段頂部
  - **壓力一 (R1)**：近 20 日最高價
  - **支撐一 (S1)**：20MA 月線支撐
  - **支撐二 (S2)**：近 20 日最低價
  - **動態防守停損線 (Stop-Loss Pivot)**
- **操盤行動指引具體股價動態替換**：
  - 全面將操盤行動指引與 Brooks 掛單指引中的抽象代號（`R1`、`R2`、`S1`、`S2`、`MA60`、`防守線`）替換為實際計算出的具體股價（例如：`以 S1（2,396.00 元，月線）作為移動停利點`、`突破 R1（2,445.00 元）放量加碼`、`跌破防守線（2,299.98 元）務必停損`），交易掛單精確無歧義。
- **K 線圖主圖全自動繪製 S/R 水平線**：
  - 🔴 **R1 近期高點**（紅色虛線）
  - 🟠 **R2 布林上軌**（橘色實線）
  - ⚪ **現價**（白色半透明點線，左側標籤）
  - 🟢 **S1 月線支撐**（綠色虛線）
  - 🔵 **S2 近期低點**（青色實線）
  - 🟣 **停損 Pivot**（紫色點線）

### 8. 🤖 100% 免費 LINE Bot 操盤秘書 ✕ 即時個人持倉與自選風控系統
- **自然語言與極速快捷操盤指令**：
  - `買 [代號] [成本] [股數]`：如 `買 2330 980`（預設 1,000 股），自動新增或加碼更新持倉，即時計算最新損益與停損位階。
  - `賣 [代號]`：如 `賣 2330`，一鍵標記平倉結案，移出持倉清單。
  - `持倉` / `庫存` / `損益`：呼叫深色質感【投資組合風控總覽】Flex 卡片，即時盤點每一檔持股現價、損益率、累計損益金額、依個股波動度自動調整之浮虧警戒價與目前防守緩衝空間。
  - `+2330` 或 `關注 2330`：極速將標的加入自選觀察名單，啟動盤中 20 EMA 支撐回測買點雷達。
  - `-2330` 或 `取消關注 2330`：移出自選名單，解除監控。
  - `自選` / `清單` / `觀察名單`：檢視所有追蹤標的現價、漲跌幅、BPA 狀態與距 20 EMA 支撐距離。
  - `[股票代號]`：如直接輸入 `2330` 或 `查 2330`，秒級回傳 1:1 復刻 Web 儀表板的旗艦級 4合1 多維綜合評鑑圖卡。
- **1:1 復刻 Web 儀表板旗艦級 4合1 多維綜合評鑑圖卡（LINE Giga Flex Message）**：
  - **頂部即時標頭**：呈現股票名稱、代號、上市/上櫃市場別、盤中即時/盤後定盤時態徽章、現價、漲跌金額與漲跌幅。
  - **決策行動橫幅**：高對比色膠囊徽章（`🟢 建議買入` / `🟡 建議持有` / `🔴 建議賣出`）、綜合評分（0~100）與星級徽章（`⭐⭐⭐⭐⭐ 優質多頭`）。
  - **4 大核心量化指標（2×2 矩陣）**：BPA 市場狀態（多頭/震盪/空頭）、20 EMA 均線數值與乖離斜率、多維量化總評級、當前 K 棒結構形態與趨勢階段。
  - **巨星多維綜合評級（4合1 暗黑矩陣）**：Minervini 趨勢樣板 7 項檢核、CANSLIM 成長動能評級、BPA 價格行為主控特徵、三大法人與 VPA 量能籌碼動態。
  - **操盤方針與關鍵支撐壓力**：精確輸出操盤方針，並標註 S1（月線防守點）與 R1（前高壓力點）具體股價。
  - **一鍵快捷下單與切換按鈕**：點擊 `買 [代號]` 快捷鈕自動帶入現價記錄持倉，點擊 `查看持倉` 隨時切換個人資產總覽。
- **盤中 60 秒即時風控與 BPA 買點雙向巡邏守護 Worker**：
  - 於台股交易日 09:00～13:35 每 60 秒批次撮合所有用戶持股與自選股。
  - **波動度自適應浮虧警戒（Volatility-Adaptive Risk Alert）**：警戒價位為 `成本 - 3 × ATR20`，並夾在 -8% ~ -15% 之間（取不到 ATR 時退回 -7%）；使用者若自訂 `stop_loss_pct` 則優先採用。跌破時推播警戒卡，提示重新評估持有理由而非機械式砍出 —— 回測實證固定 -7% 立即停損在本系統訊號下為淨損失（詳見「回測實證」一節）。
  - **自選股 BPA 底部回測買點雷達**：自選股回測 20 EMA 支撐（距離 $\le 0.8\%$ 且守穩）時主動推播多頭進場買點通知。
  - **智慧防打擾與額度守護**：內建單日單股告警去重冷卻機制，確保同一標的當天絕不重複轟炸，守護 LINE 官方每月 200 則免費 Push 額度。

### 9. ⚡ Cloudflare Worker 邊緣智慧路由器 ✕ 本機高算力極速備援 (Hybrid Edge Architecture)
為了解決雲端免費容器（如 Render 免費版）於 15 分鐘無人存取後進入休眠、導致冷啟動長達 40 秒的普遍痛點，本專案首創 **「邊緣智慧路由 ✕ 本機/雲端雙引擎」** 架構：
- **Cloudflare Edge 智慧路由器 (`cloudflare_worker/worker.js`)**：
  - 部署於 Cloudflare 全球邊緣網路，作為固定且唯一的 LINE Webhook 進入點。
  - 支援健康檢測 `/health`，動態偵測雙後端狀態並實施毫秒級瀑布式容錯（Failover）。
- **雙引擎無縫自動分流（100% 免費）**：
  - 💻 **本地電腦（高算力優先，Primary）**：當使用者開機時，透過 Cloudflare Tunnel 內網穿透將請求直接引導至本機強大 CPU，享有 **0.3 秒滿血極速回覆**（特別在批次計算持倉多股複雜量化指標時尤為顯著）。
  - ☁️ **Render 雲端（7×24 留守備援，Failover）**：當電腦關機、外出或睡眠時，Cloudflare Worker 於 1 秒內自動切換至 Render 雲端接手，確保 LINE Bot 永不失聯。
- **Cloudflare API 全自動無感同步（Zero-Touch Automation）**：
  - 本地啟動腳本內建 Cloudflare API 同步機制，開機連線產生動態穿透網址後，**自動透過 API 推送更新 Worker 密鑰 (`LOCAL_TUNNEL_URL`)**，完全無需手動複製貼上！
- **Windows 開機背景靜默與一鍵管理工具套件**：
  - 🚀 **`一鍵啟用開機自動執行.bat`**：一鍵在 Windows 開機啟動目錄註冊捷徑，每次開機於背景自動靜默運行（無黑窗干擾）。
  - 🛑 **`停止本地備援.bat`**：隨時一鍵終止本機伺服器與穿透通道，Worker 自動切回雲端。
  - 🔍 **`檢查本地備援狀態.bat`**：即時檢視本機 Port 8080 運作狀況、Tunnel 進程與開機自啟狀態。
  - ❌ **`一鍵關閉開機自動執行.bat`**：一鍵移除開機自動啟動註冊。

## 🔬 回測實證（Point-in-Time 驗證結果）

本系統的訊號準確度已以 point-in-time 回測驗證（不修改 production 程式，
改以歷史切片逐日呼叫真正的 `analyze_stock`）：2020-01 ~ 2026-06、28 檔個股、14,588 筆訊號，
進場價採訊號日次一交易日開盤（含息還原），並以「同期間隨機任一天買進」為基準做超額比較。
完整報告：`F:\DOC\finance\stock-system-accuracy-backtest.md`，工具：`backtest/`。

| 項目 | 實測結果 |
|---|---|
| BUY 訊號 20 日平均報酬 | **+4.44%**（基準 +2.25%，超額 +2.19%，95% CI [+1.46%, +2.98%]，顯著） |
| BUY 訊號 60 日平均報酬 | **+14.10%**（基準 +8.10%） |
| 看多訊號 20 日命中率 | 56.2%（基準 54.1%，僅高 2.1 個百分點） |
| 看多訊號 60 日命中率 | 63.0%（基準 58.2%） |
| SELL 訊號 20 日平均報酬 | +1.05%（仍為正報酬，顯著劣於基準 -1.20%） |
| 綜合評分 60 日橫斷面 IC | 0.140 |
| 逐檔穩定性 | 15 / 28 檔贏過自身基準 |

**使用本系統前請先理解三件事：**

1. **「高勝率」是相對的，不是絕對的。** 20 日尺度的看多命中率 56.2%，
   而同期間隨機挑一天買進本來就有 54.1% 會漲 —— 真正的增益約 2 個百分點。
   訊號的資訊集中在 **60 日尺度**，短線 5 日幾乎無效，不適合當沖或短打依據。
2. **「建議賣出」不代表會跌。** SELL 訊號後 20 日仍有 52.0% 上漲、平均正報酬。
   其價值在「相對規避、降低權重」，不在預測下跌，更不能當放空依據。
3. **邊際優勢不保證套用在單一標的。** 28 檔中僅 15 檔贏過自身基準，
   整體超額由少數個股貢獻，請勿因單一訊號放大部位。

> ⭐ 星級徽章所使用的多因子 `trend_score` 經回測其 20 日 IC 僅 0.027（近乎雜訊），
> 屬參考資訊，不應作為進出依據；決策請以綜合評分（0~100）與其 80 分門檻為準。

### 🤖 LINE Bot 操盤秘書與持倉風控系統使用說明

#### 1. 取得 LINE 官方免費金鑰（約 2 分鐘）
1. 登入 [LINE Developers Console](https://developers.line.biz/)，建立 **Messaging API Channel**。
2. 取得 **`Channel Secret`** 與 **`Channel Access Token`**。
3. 於後台關閉 **Auto-reply messages**（自動回應），開啟 **Webhook**。

#### 2. 本機執行與測試
```powershell
# 設定金鑰環境變數
$env:LINE_CHANNEL_SECRET = "YOUR_CHANNEL_SECRET"
$env:LINE_CHANNEL_ACCESS_TOKEN = "YOUR_CHANNEL_ACCESS_TOKEN"

# 啟動 Webhook 伺服器與盤中風控巡邏 Worker (Port 8080)
python line_server.py

# 自動部署並綁定深色專業 6 格常駐 Rich Menu
python setup_rich_menu.py

# 執行全套整合單元測試 (CRUD、指令、Flex、停損巡邏)
python -X utf8 test_bot_logic.py
```

#### 3. 雲端免費用戶 7×24 部署（Render Web Service 留守備援）
- 本專案已內建 `Procfile`，支援直接連結 GitHub 儲存庫一鍵部署：
  - **Environment**: `Python 3`
  - **Build Command**: `pip install -r requirements.txt`
  - **Start Command**: `python -m uvicorn line_server:app --host 0.0.0.0 --port $PORT`
  - **Environment Variables**: 設定 `LINE_CHANNEL_SECRET` 與 `LINE_CHANNEL_ACCESS_TOKEN`

#### 4. ⚡ 部署 Cloudflare Edge 智慧路由器（解決休眠延遲）
1. 進入 [Cloudflare Dashboard](https://dash.cloudflare.com/) ➔ **Workers & Pages** ➔ **Create Application** ➔ **Create Worker**。
2. 命名為 `tw-stock-bpa-router`，將 `cloudflare_worker/worker.js` 代碼貼上並點擊 **Deploy**。
3. **設定環境變數 (Settings ➔ Variables)**：
   - `RENDER_BACKEND_URL`: 填入你的 Render 網址（如 `https://tw-stock-bpa-bot.onrender.com`）。
4. **設定 LINE Webhook**：
   - 將 LINE Developers 後台的 Webhook URL 固定設定為：`https://<你的-worker-名稱>.<帳號子域>.workers.dev/callback` 並 Verify 驗證。以後無論本機網址如何變動，LINE 後台永遠不必再改動！

#### 5. 🚀 本機極速備援與開機全自動執行（解法 A）
1. **設定 `.env` 檔**（位於專案根目錄）：
   ```ini
   LINE_CHANNEL_SECRET=你的_LINE_SECRET
   LINE_CHANNEL_ACCESS_TOKEN=你的_LINE_TOKEN
   CF_ACCOUNT_ID=你的_Cloudflare_Account_ID
   CF_API_TOKEN=你的_Cloudflare_API_Token
   ```
2. **一鍵啟用開機自動執行**：
   - 雙擊執行目錄下的 **`一鍵啟用開機自動執行.bat`**。
   - 系統將自動在 Windows 開機啟動目錄建立捷徑，每次開機後台靜默自動連線穿透並透過 API 同步網址。
3. **日常管理捷徑**：
   - **`檢查本地備援狀態.bat`**：即時查看本機 Port 8080、Tunnel 與開機自啟狀態。
   - **`停止本地備援.bat`**：隨時一鍵終止本機服務，Worker 自動將流量無縫轉回 Render 雲端。

#### 6. 🔥 配置 Firebase Firestore 雙節點資料同步（解決雲端備援與本地資料不同步）
本系統支援將本地的 SQLite 暫存資料以**低成本增量同步 (Delta Sync)** 的方式上傳至 Firebase Firestore，確保本地端與 Render 雲端節點的資料永遠保持同步，並且不會超過免費額度：
1. 進入 [Firebase Console](https://console.firebase.google.com/) 建立一個新的 Firebase 專案。
2. 進入 **Cloud Firestore**，點擊 **Create database**。
3. **重要**：請建立「原生模式 (Native Mode)」的資料庫，並將資料庫名稱保持預設的 **`default`**，位置可選 `asia-east1` (台灣)。
4. 進入專案設定 ➔ **服務帳戶 (Service Accounts)** ➔ **產生新的私鑰 (Generate new private key)**。
5. 將下載的 JSON 檔案重新命名為 **`firebase_key.json`** 並放入本專案的根目錄。
6. 系統偵測到 `firebase_key.json` 後，便會自動啟用雙節點同步機制。
