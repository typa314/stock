# 台股 K 線量價 + 三大法人分析工具 (Taiwan Stock K-Line & Institutional Analysis)

這是一個專為台股設計的量價與籌碼分析工具，支援上市（TWSE）與上櫃（TPEX）股票的歷史 K 線、成交量均線、三大法人（外資、投信、自營商）買賣超分析，並可一鍵產出 Plotly 互動式三層圖表與終端研判摘要。

---

## 🌟 功能特點

1. **上市 / 上櫃全自動支援**：
   - 上市股票（TSE）：串接 TWSE 官方 API 與 OpenAPI 取得完整歷史與當日即時收盤。
   - 上櫃股票（OTC）：自動辨識並串接 yfinance（`.TWO`）歷史行情。
   - 自動判斷股票所屬市場與名稱。

2. **三大法人買賣超籌碼分析（上市股票）**：
   - 抓取近 30 個交易日的外資、投信、自營商每日買賣超（張數）。
   - 判斷連續買超/賣超天數與近 5 日主力動向。

3. **量價形態與技術指標自動偵測**：
   - **均線系統**：MA5（短線）、MA20（月線）、MA60（季線）、VOL MA20（成交量均線）。
   - **放量突破**：收盤創 20 日新高且成交量大於 1.5 倍均量。
   - **量縮回測**：股價貼近 MA5 且成交量萎縮至均量 70% 以下。
   - **量價背離**：連續價跌量增等空方背離警示。

4. **互動式三層可視化圖表**：
   - **頂層**：K 線蠟燭圖 + 均線 + 成本線 + 形態標註。
   - **中層**：三大法人買賣超柱狀圖（分群呈現外資、投信、自營商）。
   - **底層**：成交量（漲紅跌綠）+ 20 日成交量均線。
   - 支援縮放、懸浮詳細資訊、自動排除週末空白交易日。

## 📦 安裝說明

建議使用 Python 3.9+ 環境：

```powershell
pip install -r requirements.txt
```

---

## 🚀 使用方法

```powershell
# 1. 基本分析（指定代號）
python -X utf8 kline.py 3042

# 2. 指定自訂名稱與持有成本（圖表會標示成本線與損益）
python -X utf8 kline.py 3042 --name 晶技 --cost 190

# 3. 分析上櫃股票
python -X utf8 kline.py 6643 --name M31

# 4. 指定分析月數（預設 12 個月）
python -X utf8 kline.py 2330 --name 台積電 --cost 850 --months 6
```

### 參數說明

| 參數 | 說明 | 預設值 | 必填 |
|---|---|---|---|
| `ticker` | 台股代號（純數字，如 `3042`、`2330`、`6643`） | - | ✅ |
| `--name` | 自訂股票名稱（如 `晶技`） | 自動查詢 | ❌ |
| `--cost` | 個人持有成本（元），圖表將繪製黃色虛線並計算損益 % | `None` | ❌ |
| `--months`| 歷史分析月數 | `12` | ❌ |
