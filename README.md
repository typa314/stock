# 📊 台股專業多維量價 + 籌碼 + 技術形態研判系統 (Taiwan Stock Quantitative & Technical Analysis)

本專案是一個專為台股（上市/上櫃）打造的專業級量價結構、技術形態、動量指標與三大法人籌碼多維研判系統。支援一鍵產出 **Plotly 互動式多層分析圖表** 與 **終端多因子專業量化研判報表**。

---

## 🌟 核心架構與功能特點

### 1. 🏛️ 上市 / 上櫃全自動支援
- **上市股票（TSE）**：自動串接 TWSE 官方 API 與 OpenAPI 取得完整歷史交易、當日即時收盤與三大法人數據。
- **上櫃股票（OTC）**：自動辨識並串接 yfinance（`.TWO`）歷史行情。
- **智慧代號解析**：輸入純數字代號（如 `3042`、`6643`）即可自動判定市場類別與官方股票簡稱。

### 2. 🧭 Stan Weinstein 四階段趨勢結構
- 不僅比對均線高低，更量化計算 **20MA（月線）與 60MA（季線）近 5 日斜率（Slope）**：
  - **第 1 階段（築底打底）**：季線下彎趨緩、月線走平糾結，進入區間打底。
  - **第 2 階段（主升推進）**：MA20 > MA60 且月線/季線雙雙向上發散，沿均線走高。
  - **第 3 階段（高檔做頭）**：股價創高後均線鈍化走平，出現高檔長上影或爆量滯漲。
  - **第 4 階段（主跌修正）**：MA20 < MA60 且月線/季線雙雙向下發散，逢反彈皆空點。

### 3. 🎯 經典 Price Action 形態與 Wyckoff 量價分析
- **K 線形態識別**：
  - **多頭吞噬 / 空頭吞噬**（Engulfing Pattern）
  - **長下影錘子線**（Hammer，低檔承接）
  - **長上影流星線**（Shooting Star，高檔反壓）
  - **母子孕線**（Inside Bar）
- **量價結構檢測**：
  - **放量突破**（收盤突破 20 日高點 + 成交量 > 1.5 倍均量）
  - **量縮回測**（股價貼近 MA5 ±1.5% 且成交量萎縮至均量 75% 以下）
  - **爆量滯漲 / 出貨警訊**（成交量 > 1.8 倍均量且留長上影線）
  - **極度窒息量**（成交量萎縮至均量 45% 以下，變盤前夕）
  - **指標頂/底背離（Divergence）**：檢測價格與 RSI/MACD 之背離反轉訊號。

### 4. 🏢 三大法人籌碼結構剖析（上市股票）
- 每日追蹤 **外資、投信、自營商** 買賣超數據（張數）。
- 計算法人買賣佔當日成交量比重（籌碼集中度）。
- 自動判定 **土洋聯手做多 / 土洋聯手殺盤 / 土洋對作** 態勢。

### 5. 🎯 關鍵支撐壓力矩陣與操盤指引
- 自動計算：
  - **壓力二 (R2)**：布林通道上軌 / 波段頂部
  - **壓力一 (R1)**：近 20 日最高價
  - **支撐一 (S1)**：20MA 月線支撐
  - **支撐二 (S2)**：近 20 日最低價
  - **動態防守停損線 (Stop-Loss Pivot)**
- 針對 **【持股者】** 與 **【空手者】** 分別輸出量化操作策略。

### 6. 📈 互動式五層圖表（Plotly Interactive Charts）
- **Row 1**：K 線蠟燭圖 + MA5/20/60 + 布林通道 (20, ±2σ) + 形態標註 + 個人持股成本線。
- **Row 2**：三大法人買賣超柱狀圖（分群呈現外資、投信、自營商）。
- **Row 3**：MACD (12, 26, 9) DIF / Signal / 柱狀圖。
- **Row 4**：RSI (14) 強弱指標 + 70 超買 / 30 超賣基準線。
- **Row 5**：成交量（漲紅跌綠）+ 20 日成交量均線。
- 自動排除週末非交易日空白，支援自由平移、縮放、懸浮游標。

## 🚀 使用方法

```powershell
# 1. 基本分析（預設近 2 個月）
python -X utf8 kline.py 3042

# 2. 指定自訂名稱與持股成本（圖表會標示成本線與損益）
python -X utf8 kline.py 3042 --name 晶技 --cost 190

# 3. 分析上櫃股票
python -X utf8 kline.py 6643 --name M31

# 4. 指定分析月數（例如 6 個月）
python -X utf8 kline.py 2330 --name 台積電 --cost 850 --months 6
```

### 參數說明

| 參數 | 說明 | 預設值 | 必填 |
|---|---|---|---|
| `ticker` | 台股代號（純數字，如 `3042`、`2330`、`6643`） | - | ✅ |
| `--name` | 自訂股票名稱（如 `晶技`） | 自動查詢 | ❌ |
| `--cost` | 個人持有成本（元），圖表將繪製黃色虛線並計算損益 % | `None` | ❌ |
| `--months` | 歷史分析月數 | `2` | ❌ |
